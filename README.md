# Psid2cpp
Initial version of Simple Converter.<br>
You might ask, who needs a program like this? I do ;).<br><br>

While writing a Commodore C64 music player for an STM32 or ESP32, I needed to quickly test the code. Without SD card support, it was difficult to simply load data into memory.<br>
And this converted file was perfect for that.<br>
Of course, the file itself isn't everything. Support for a virtual 6502 processor, which will emulate the C64 processor, needs to be added.
